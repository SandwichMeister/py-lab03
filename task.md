# Лабораторная работа 3. Каталог объектов

## Результат

Пакет с предметной моделью и каталогом объектов. Вариант предметной области назначает преподаватель:

- библиотечные книги;
- авиационные детали;
- медиатека;
- учебные аудитории;
- транспортные маршруты.

## Сущность

Использовать `dataclass`. Сущность содержит:

- уникальный строковый идентификатор;
- название;
- категорию;
- год или дату;
- минимум два поля варианта.

Инварианты проверяются при создании. Неверный объект не должен появляться в каталоге.

## Каталог

Реализовать:

```python
add(item) -> None
get(item_id)
remove(item_id)
find_by_category(category)
find_by_name(query)
__len__()
__iter__()
__contains__(item_id)
```

Требования:

- поиск по ID выполняется через словарь;
- дубликат ID запрещён;
- поиск по имени нечувствителен к регистру;
- порядок итерации документирован и детерминирован;
- методы поиска не возвращают внутренний изменяемый список каталога;
- удаление отсутствующего ID вызывает предметное исключение.

## Хранение

- Сохранение каталога в JSON.
- Загрузка каталога из JSON.
- Поле `format_version` в корне документа.
- Повреждённый документ не должен частично изменять существующий каталог.

## Исключения

Создать базовое `CatalogError` и отдельные ошибки:

- неверная сущность;
- дубликат ID;
- объект не найден;
- неподдерживаемая версия формата;
- повреждённый файл.

## Тесты

- Создание допустимой и недопустимой сущности.
- Добавление, получение и удаление.
- Дубликат ID.
- Поиск по категории и имени.
- Порядок итерации.
- Round trip JSON.
- Повреждённый JSON и неизвестная версия.
- Проверка отсутствия частичного изменения после ошибки загрузки.
