## Обязательные проверки

- Неверная сущность отклоняется при создании.
- Два объекта с одним ID не могут находиться в каталоге.
- `get` не выполняет линейный поиск по всей коллекции.
- Поиск имени работает с разным регистром.
- Результат поиска нельзя использовать для прямого изменения внутреннего списка.
- Итерация дважды даёт документированный порядок.
- Сохранение и загрузка сохраняют все поля.
- Неизвестная версия формата отклоняется.
- При ошибке в середине файла исходное состояние каталога сохраняется.
- Удаление обновляет все реализованные индексы.
